About the app

A focus timer that keeps the record on your machine

DeepWork is a free, open-source Pomodoro timer, task manager, day planner and habit tracker for Windows, macOS, Linux and the browser. There is no account, no cloud sync and no subscription. Your tasks, focus sessions, habits and journal entries live in a database you own.

What it does

DeepWork is built around a focus session. You pick a task, start a block, and the app keeps the time, rings until you answer, and records the session against the work it paid for. The rest of the app exists to make that loop useful over weeks rather than minutes.

  • Focus timer. Pomodoro-style sessions with short and long breaks, configurable lengths, an animated ring and completion alerts that repeat until answered.
  • Tasks. A status board, a Today view, search, recurrence, Excel/CSV import with a validated preview, and CSV export.
  • Eisenhower matrix. Four quadrants with drag and drop, feeding the day's plan.
  • Calendar and day planner. Tasks placed into focus blocks at the timer's own block length, with breaks reserved.
  • Time by Task. Every session grouped by the work's title, with all-time totals, first and last session, a rhythm and a custom range.
  • Habits and journal. Daily habits with streaks, and dated journal entries with word counts.
  • Analytics. Focus, task, habit and journal figures with trends, each paired with a plain-language reading computed on your machine.
  • Standing reminders. Stored reminders that survive a restart and keep asking until Done, Snooze or Stop.

Where your data lives

On the desktop builds, DeepWork keeps a SQLite database file in your operating system's application-data folder. In the browser build, the same records are kept in that browser's local storage for the address you opened it from. Neither build has a DeepWork backend to send them to.

You can export a JSON backup and import it into another copy. You can delete records from inside the app. Removing the app, clearing the browser's site data or deleting the database file removes them permanently — DeepWork cannot restore what it never had.

No sync, stated plainly. Each machine has its own database. A backup can be moved by hand, but there is no account and no multi-device sync. If that is a requirement, DeepWork is the wrong tool and the timer guide explains the trade.

What it costs, and what it does not do

DeepWork is free. There is no paid tier, trial, account or card. The source is MIT licensed, so you can inspect it, fork it and keep using the version you have if the project stops.

The limits are worth stating as clearly as the features:

  • No cloud or multi-device sync.
  • No team, sharing or collaboration features.
  • No native iOS or Android app.
  • The desktop installers are unsigned, so Windows SmartScreen and macOS Gatekeeper warn on first launch.
  • The desktop app contacts GitHub's public releases API to check for updates, and downloads an installer only when you press Update.

Who builds it

DeepWork is built by Rajat Malik, a senior lead software engineer with more than sixteen years of experience building and leading software delivery. It started as a personal tool: a timer, a task list and a record of where the week went, without signing up for another service to get them. It is released for anyone who wants it, as a personal project rather than a product with a support contract.

The app is built with Tauri 2 and Angular. The source, issue tracker and releases are on GitHub.
